# Roadmap

## Phase 0 — Foundation
- [ ] Create Unreal C++ project and build on a clean machine
- [ ] Configure Git LFS for large source assets if needed
- [ ] Establish coding conventions and CI

## Phase 1 — Playable prototype
- [ ] Third-person movement and camera
- [ ] Lock-on target
- [ ] Basic melee combo, dodge, block
- [ ] Health, stamina, hit reactions
- [ ] One original test arena and training dummy

## Phase 2 — Abilities and progression
- [ ] Ability data assets and cooldowns
- [ ] Energy resource
- [ ] Transformation state machine
- [ ] XP, unlocks, and save/load

## Phase 3 — Modding
- [ ] Versioned manifest schema
- [ ] Validator and clear error reports
- [ ] Mod browser and enable/disable list
- [ ] Conflict rules and compatibility tests

## Phase 4 — Worlds and authoring
- [ ] World settings and weather presets
- [ ] Arena/world streaming
- [ ] Quest and NPC data
- [ ] Editor utility widgets

## Phase 5 — Platform expansion
- [ ] PC optimization and packaging
- [ ] Android performance and touch controls
- [ ] Evaluate console certification and mod restrictions
